# 柚月兼容合集

这是一个独立的 SillyTavern 第三方扩展（v0.2.3），合并了本地制作的两项兼容修复：

- **小猫之神 / 喵赛亚**：去重 SPreset iframe，并把柚月记忆拆分出的 `assistant` 消息合并回 Final Request 需要的 `system → assistant → user` 形状。
- **DIE**：恢复柚月记忆处理过程中被删掉的带签名 assistant/tool 消息，并保持工具调用传输格式。

扩展菜单中的“柚月兼容合集”面板支持每项 **自动 / 开启 / 关闭**。助手已读取当前酒馆预设列表，自动模式只匹配实际的小猫之神系列名称（如 `【DarkSide-小猫之神】v1.1`、`【小猫之神·喵赛亚】1.5`、`【小猫之神】3.11`、`【小猫之神】4.0test`、`【小猫之神Reborn】1.0`）和 DIE 系列名称（`【DIE】4.1 - Astro`、`【DIE】Astro 3.7`、`【DIE】Cosmo 3.7 0821`）。只有名称命中时才自动启用；其他含有通用 `SPreset` 或 `SoliUmbra` 的预设需要手动开启。

兼容逻辑按功能隔离：普通预设下不安装 SPreset iframe 观察器，也不改写柚月记忆的请求数组；切换到目标预设后才启用对应处理。小猫之神和 DIE 预设切换时，如果页面上残留多个 SPreset iframe，合集只保留当前系列对应的一个（同类重复保留最新实例）。合集只包裹 `YuzukiMemory.VariableInjector.processBody`，并保留原函数返回值与字段，柚月记忆主体开关关闭时不会执行兼容处理。

## 安装

在 SillyTavern 的扩展菜单选择安装第三方扩展，填入本仓库 URL。安装后刷新页面。合集会先于旧的两个本地修复扩展加载；旧扩展可以保留，合集会通过全局标记避免重复包装。发布到 GitHub 后，manifest 已启用自动更新。

## 柚月记忆更新失败说明

SillyTavern 的更新接口会直接执行 `git pull`。柚月记忆目录存在本地未提交修改或未跟踪文件时，Git 会拒绝合并，所以会表现为“更新不了”。合集不自动覆盖这些修改，也不执行 reset/clean。更新前请先备份本地改动；若需要保留改动，先在服务器终端完成提交或导出，再更新扩展。

“复制诊断”按钮只复制当前运行时状态，不包含 Token、Cookie 或聊天内容。
